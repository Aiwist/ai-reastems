# История изменений Ai ReaStems

## Не выпущено

- README для GitHub дополнен описанием возможностей и скриншотами главного окна и настроек.

## 0.2.5 — 2026-11-21

- Исправлен запуск установщика Windows. Окно лицензий открывается при запуске через `Установить.bat`.
- Добавлены описание выпуска и инструкция по установке для GitHub.

## 0.2.4 — 2026-11-21

- Проект переименован в Ai ReaStems. Обновлены имя окна, путь установки, папки и установочный архив для Windows.
- В главном окне можно выбрать только установленные модели. Установка доступна в настройках.

## 0.2.3 — 2026-11-20

- Кнопка «Открыть папку» работает с существующими папками моделей и данных в Windows.
- Ошибки записываются локально. Из главного окна и настроек можно сохранить ZIP-отчёт с диагностикой.
- В настройках пути к папкам моделей и данных можно выделять, копировать и менять прямо в поле. Текущие папки открываются в Проводнике Windows.
- Кнопка установки выбранной модели в главном окне теперь активна и визуально отделена от карточки. Размер загрузки виден в подсказке.
- Добавлен собственный установщик Ai Stems для Windows x64 с выбором профиля REAPER, ReaImGui и встроенной сборкой stems.cpp Vulkan/CPU.
- В настройках доступны 13 моделей stems.cpp, выбор папок данных и загрузки моделей, ручная проверка и установка обновлений движка.
- Уже скачанные модели Ai Transcriber Plus можно использовать в Ai Stems без повторной загрузки.
- Раздел «Модель и оборудование» переименован в «Модель разделения». Выбор CPU перенесён в настройки движка.
- Исправлено падение ReaImGui при открытии главного окна Ai Stems.
- Добавлено отдельное окно Ai Stems для Windows с выбором источника по выделению REAPER.
- HTDemucs, HTDemucs FT и HTDemucs 6s разделяют композиции, MDX23C DrumSep — барабанное аудио. Можно выбрать дорожки для вставки.
- Подготовка аудио учитывает активные тейки, скорость, стретч-маркеры и расположение фрагментов на одной дорожке.
- Первая сборка использовала установленный Ai Transcriber Plus для разделения. Текущая сборка запускается самостоятельно.
